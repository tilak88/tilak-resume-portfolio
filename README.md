# Tilak Sharma - Resume and Project Workspace

This workspace contains two CCD-compliant one-page resumes, the final upload-proof checklist, and three independently organized project repositories.

## Important CCD exclusions

Admission-based examination ranks, scores, and percentiles, including GATE, are intentionally excluded from both resumes. Unsupported claims are not silently retained.

## Project repositories

- [tilak-binoculars-extensions](https://github.com/tilak88/tilak-binoculars-extensions) - independent Binoculars baseline and feature-fusion implementation.
- [tilak-macro-placement](https://github.com/tilak88/tilak-macro-placement) - independent ML-for-EDA macro-placement implementation.
- [evigraph-document-intelligence](https://github.com/tilak88/evigraph-document-intelligence) - thesis evidence-graph prototype.

Build the resumes with `scripts/build_resumes.ps1`. Source PDFs and private verification documents remain local and are excluded from this workspace repository.
